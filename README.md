# proposta-drt

Proposta comercial da Enxerga em formato de site. Publicado em https://proposta-drt.enxerga.net (não indexado).

## Publicar
1. GitHub → Settings → Pages → Deploy from a branch → `main` / `(root)`.
2. Custom domain: `proposta-drt.enxerga.net` → marcar "Enforce HTTPS".
3. DNS do enxerga.net: `CNAME proposta-drt → lucaserbano.github.io`.

## Valores
Os valores ficam em `assets/js/pacote.js`. Testes: `node --test`.
